VIP Web - النسخة المصححة والقابلة للتشغيل محلياً

المتطلبات: Node.js 22 أو أحدث.

التشغيل:
1) افتح Terminal داخل مجلد المشروع.
2) شغّل: node server.js
3) افتح المتصفح على: http://localhost:3000

الدخول الأول:
admin / 1234

قاعدة البيانات SQLite محلية داخل data/vip.sqlite، ولا تحتاج PostgreSQL أو npm install.
هذه النسخة صُممت لتكون قابلة للتشغيل فوراً، ويمكن نقل قاعدة البيانات لاحقاً إلى PostgreSQL دون إعادة تصميم الواجهة.
